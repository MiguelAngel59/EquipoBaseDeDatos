Resumen
En esta práctica se realizaron consultas SQL que utilizan funciones de agregación como COUNT, SUM, AVG, MIN y MAX, combinadas con cláusulas GROUP BY para agrupar registros y HAVING para filtrar grupos según condiciones agregadas. Aplicamos estas herramientas para construir consultas personalizadas que analizan datos de vuelos, aviones, aerolíneas y empleados, para obtener información puntual de utilidad.

Instrucciones:
- Abrir pgAdmin, y establecer la conexión con una base de datos de prueba
- Copiar y pegar el contenido de los siguientes archivos (en el queryTool)
  1. DDL.sql o DDLshort.sql, se ubica en EquipoBaseDeDatos/SQL/DDL/       (Creación de tablas)
  2. DML.sql, se encuentra en EquipoBaseDeDatos/SQL/DML/                  (Inserciones de elementos en las tablas)
  3. Abrir consultas_agregación, se encuentra en EquipoBaseDeDatos/SQL/DML/
  4. Copiar y pegar cada consulta que se quiera probar
